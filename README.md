# ShuntView — Imaging Workstation Demo

션트 밸브 조절 단계 분류 기술을 설명하기 위한 의료영상 워크스테이션 형태의 시연 사이트입니다. **실제 AI 추론 없이 약 220 ms 뒤 파일명에 기록된 단계를 표시합니다.** 환자 정보나 실제 의료영상이 없는 가상 도식을 기본 예시로 제공합니다.

## 화면과 조작

- 왼쪽 사례 목록, 가운데 AP/LAT 원본과 패치, 오른쪽 조절 단계 및 영상 조절 도구
- 휠 확대/축소, 드래그 이동, 원본 속 밸브 위치로 확대
- ±90° 및 1° 단위 자유 회전, 좌우 반전, 흑백 반전
- 밝기·대비 조절 및 드래그 윈도잉
- 수동 밸브 영역 지정, 영상 하나 크게 보기, 전체 화면
- DEMO 표시가 포함된 결과 PNG 저장

## 데이터 넣기

```text
shunt_data/
  anterior/
    images/case001_1.0.png
    images_patch/case001_1.0.png
  lateral/
    images/case001_1.0.png
    images_patch/case001_1.0.png
```

원본과 패치, AP와 LAT의 사례 이름을 맞춰 주세요. `AP_` / `LAT_` / `anterior_` / `lateral_` 접두사 및 `_patch` 역할 표시는 자동으로 정리합니다. 파일명 맨 끝의 `0.5`, `1.0`, `1.5`, `2.0`, `2.5`를 읽습니다. 서로 다른 단계 값이 발견되거나 같은 사례의 이미지가 중복되면 임의로 결정하지 않고 분석을 비활성화합니다.

PNG/JPG/WebP/BMP 지원. DICOM/TIFF는 지원하지 않습니다.

### PC 폴더에서 바로 열기

사이트 상단 **폴더 열기** → PC의 `shunt_data` 폴더 선택. 선택한 파일은 브라우저 안에서만 읽고 서버에 올리지 않습니다. 폴더 구조가 맞으면 AP/LAT와 패치를 자동 연결합니다.

### GitHub 저장소에 올리기

이 프로젝트 전용 저장소에 `shunt_data`를 업로드하면 GitHub Actions가 사례 목록을 생성하고 GitHub Pages를 갱신합니다. 공개 사이트에 올릴 수 있는 비식별 예시 영상만 사용하세요. GitHub Pages는 공개 URL입니다.

처음 한 번 저장소 **Settings → Pages → Source → GitHub Actions**로 설정합니다. 이후 `main`에 올리면 자동 배포됩니다. 자기소개 홈페이지 저장소와는 독립적으로 사용합니다.

## 밸브 위치

`images_patch`의 전체 이미지를 원본과 대조하여 패치 위치를 추정하고, 그 가운데 부분을 밸브 영역으로 표시합니다. 실제 학습 모델의 검출 결과가 아닙니다. 대조가 불확실하면 임의 위치를 만들지 않습니다. **영역 지정** 도구로 원본 위에서 직접 보정할 수 있습니다.

패치 뷰어는 처음에 이미지 중심부를 180% 확대합니다. 확대 비율·회전·밝기·반전은 네 영상마다 독립적입니다. 수동 지정과 조작 상태는 브라우저 메모리에만 유지됩니다.

## 로컬 실행

```bash
python scripts/build_manifest.py
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다. 별도 모델이나 백엔드가 필요하지 않습니다. 파일을 더블클릭해서 실행하려면 배포 패키지의 `ShuntView-standalone.html`을 사용합니다.

```bash
node --test tests/data.test.mjs
```

`build_manifest.py`는 OpenCV가 있으면 위치를 미리 대조합니다. 없으면 사례 목록만 생성하고, 뷰어가 브라우저에서 패치를 대조합니다. 가상 예시는 실제 환자 영상이 아닌 직접 만든 SVG 도식입니다. 임상 판단용 소프트웨어가 아닙니다.
