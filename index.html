ShuntView 사용 안내

AI 분석 실행을 누르면 약 220 ms 후 파일명에 기록된 조절 단계를 표시합니다. 실제 모델이 연결되지 않은 시연 화면입니다.

확대 / 이동
영상 위에서 마우스 휠로 확대하고 드래그로 이동합니다. ‘밸브 확대’는 지정된 밸브 위치로 이동합니다.
회전 / 반전
조절할 영상을 먼저 클릭한 뒤 ±90° 버튼, 회전 슬라이더, 좌우 반전을 사용합니다.
밝기 / 대비
오른쪽 슬라이더를 사용하거나 ‘밝기/대비’ 도구를 선택해 드래그합니다.
영역 지정
AP 또는 LAT 원본 영상에서 밸브를 둘러싸도록 드래그하면 위치가 갱신됩니다.
폴더 열기
PC의 shunt_data 폴더를 선택합니다. 선택한 이미지는 브라우저 안에서만 사용하며 서버로 전송하지 않습니다.
shunt_data/
　anterior/images/　　원본
　anterior/images_patch/　패치
　lateral/images/　　 원본
　lateral/images_patch/　패치

같은 사례는 원본·패치와 AP·LAT에서 같은 파일명을 사용하면 자동 연결됩니다. case001_1.0.png처럼 파일명 끝의 0.5 / 1.0 / 1.5 / 2.0 / 2.5를 단계로 읽습니다.

원본 속 위치는 패치 대조로 추정합니다. 대조가 어렵거나 위치가 맞지 않으면 ‘영역 지정’으로 보정하세요. 패치 화면은 처음에 중심부를 확대합니다. 휠로 전체 패치를 볼 수 있습니다.

PNG / JPG / WebP / BMP 지원 · DICOM 미지원 · 가상 예시에는 환자 영상이 포함되어 있지 않습니다.
